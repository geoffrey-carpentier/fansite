# Fan Site

**Note** : Ce projet a été réalisé dans le cadre de ma formation de Développeur Web et Web Mobile (DWWM) au sein de La Plateforme.

Ce dépôt contient un projet de site statique appelé "Fan Site", dédié à un sujet de passion (dans ce cas, Bitcoin, la blockchain et son écosystème). Ce projet a pour but de valider les acquis de base en intégration web (HTML5 et CSS3).

## Fonctionnalités principales

- **Pages de contenu** : Plusieurs pages HTML structurées sémantiquement (Accueil, Histoire, Blockchain, Mining, Satoshi Nakamoto, etc.).
- **Mise en page CSS** : Utilisation du CSS (`fansite.css`) pour la stylisation, la typographie et la mise en page.
- **Navigation** : Menu de navigation fonctionnel reliant toutes les pages entre elles.
- **Multimédia** : Intégration de ressources visuelles (images, vidéos) pour enrichir le contenu.

## Installation et utilisation

Ce projet est purement statique et ne nécessite aucun serveur ou base de données.

1. Clonez ce dépôt sur votre machine :
   ```bash
   git clone https://github.com/geoffrey-carpentier/fansite.git
   ```
2. Ouvrez simplement le fichier `index.html` dans n'importe quel navigateur web moderne pour commencer la navigation.
